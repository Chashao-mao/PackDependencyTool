# Contributing

- Use .NET 9 SDK and build the solution with `dotnet build`.
- Run `dotnet test tests/PackDepTool.Core.Tests/PackDepTool.Core.Tests.csproj`.
- Do not add bundled mod translation indexes, MC百科/PCL-CE data, API keys or
  third-party modpack archives.
- Do not copy code from PCL/PCL-CE or RimCrow without checking its license and
  documenting the attribution.
- Keep the portable `data` directory out of commits.
- By submitting a contribution you agree that it is licensed under the MIT
  License of this repository.
