# Pack Dependency Tool

一个 Windows 桌面端的 **Minecraft 模组关系管理器**。用来查看整合包里模组之间的必需、可选、冲突、内嵌和手动关系，交互类似 RimCrow 的关系管理。

## 能做什么

- **关系清单**：按问题优先排列，模组之间有依赖轨道连接，一眼看到谁依赖谁。
- **关系图**：缩放、平移、框选、点击节点或关系查看详情；可只看某个模组的相关关系。
- **关系详情**：依赖、被依赖、冲突、可选、内嵌和手动关系分组展示，支持定位。
- **手动关系**：自己补充、修改、删除模组之间的关系。
- **规则与报告**：忽略指定问题、覆盖版本范围、导出关系报告。
- **问题检查**：缺失依赖、声明冲突、版本不匹配、循环依赖。
- **获取内容**：下载模组或整合包，导入本地整合包；也可获取游戏本体和加载器，并自定义实例名称。

## 快速开始

1. 下载并双击 `PackDependencyTool.exe`。
2. 点「选择整合包」，选择整合包目录；也可以直接把目录拖进窗口。
3. 点「扫描」。
4. 在左侧筛选、中间清单/关系图、右侧详情之间查看关系。
5. 双击已选模组可切到关系图并定位。

## 常用入口

- **选择整合包 / 扫描**：打开并分析整合包。
- **获取内容 ▾**：下载模组、下载整合包、导入本地整合包、获取游戏本体 / 加载器、切换加载器。
- **导出 ▾**：JSON、DOT、GraphML、CSV、Markdown 报告和 `.mrpack`。
- **更多 ▾**：检查更新、实例目录、模组历史、工具箱等。
- **设置**：更新源、下载并发数、主题等。

## 系统要求

- Windows 10 / 11 x64
- 发布版为自包含单文件，不需要另外安装 .NET
- 需要联网的部分：模组/整合包搜索、图标、在线补全和更新检查

## 更新

默认手动检查更新；自动检查、自动下载和自动重启更新都在设置中，默认关闭。更新需要 `update.json` 提供并匹配 SHA256。

## 说明

- 本工具不是启动器：账号登录、Java 启动和启动游戏仍交给启动器。
- 不附带第三方中文译名索引；中文名来自用户自定义。
